## 🎯 Core Actions

### **🆕 Create Session** (PO/SM)
1. Login → Leave Session ID blank → **"Create Session"**
2. **Copy session URL** → Share with team

### **🤝 Join Session** (All)
1. **Click shared URL** → Login → Auto-join
2. OR: Login → Enter Session ID → **"Join Session"**

### **📝 Add Stories** (PO/SM)  
1. Enter **Story Number** (e.g., US-001)
2. Enter **Story Summary** 
3. **"Add Story"**

### **🎯 Estimate Stories** (All)
1. Read story summary
2. **Click point value**: `0, 0.5, 1, 2, 3, 5, 8, 13`
3. Add reasoning if prompted

### **📊 View Dashboard** (All)
1. **"Toggle Dashboard"** → View analytics
2. **"📥 Download Summary"** → Export CSV

## 🛠️ Quick Troubleshooting

| Problem | Quick Fix |
|---------|-----------|
| **"Session not found"** | Refresh page or create new session |
| **Can't copy link** | Copy browser URL manually |  
| **Estimates not updating** | Refresh browser (F5) |
| **Dashboard errors** | Close dashboard → Reopen |
| **Mobile display issues** | Use landscape mode |

## 📞 Emergency Actions

### **🚨 If Tool Breaks**
1. **Refresh browser** (Ctrl+F5)
2. **Try different browser** (Chrome recommended)
3. **Clear browser cache**
4. **Create new session** if needed

### **💾 Save Your Work**
- **Export CSV** before closing session
- **Copy session URL** for future access
- **Screenshots** of important estimates

---

## 👥 Team Workflow

### **📋 Recommended Process**
1. **PO creates session** → Shares URL
2. **Team joins** → All login with roles
3. **Add all stories first** (PO/SM)
4. **Estimate individually** → Discuss differences  
5. **Use dashboard** → Review & export
6. **Mark stories complete** as developed (PO)

### **🎯 Session Best Practices**
- **3-8 people** optimal team size
- **2+ hour sessions** for thorough estimation
- **Discuss stories** before estimating  
- **Export data** for sprint planning
- **Regular breaks** for long sessions
